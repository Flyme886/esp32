# 本机素材（不会上传到 GitHub）

把这几个文件放在这个文件夹里：

| 文件 | 用途 |
| --- | --- |
| `wa1.png` | 第 1 级（初始奶娃） |
| `wa2.png` | 第 2 级 |
| `wa3.png` | 第 3 级（大笑） |
| `laugh.wav` | 第 3 级出现时循环播放的笑声；也可以放 `laugh.mp4`，脚本会自动截取第 1–4 秒 |

图片用白色或浅色纯背景即可，脚本会自动抠掉背景。

放好后在 `pin-hao-wa` 文件夹里运行：

```bash
python3 tools/build_assets.py
```

这个文件夹里除了本说明，其他文件都被 `.gitignore` 排除，不会提交。
